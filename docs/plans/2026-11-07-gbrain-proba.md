## Что сломалось по пути
1. **Рекомендованная гайдом регистрация (stdio) не годится для PGLite.** Каждый запуск Hermes порождает свой `gbrain serve`, база однопользовательская: второй процесс получает `pglite_busy`. Реальный вызов из `hermes -z` отвечал «lock_held». Решение: один общий `serve --http` как служба, Hermes ходит по HTTP с токеном. Это отход от `docs/mcp/HERMES.md`.
2. Поверхность `starter` + `--advertise verbs` отдаёт Hermes только 8 глаголов: `remember`, `recall`, `entity`, `forget`, `context_pack`, `delta`, `synthesize`, `request_tools`. Прямого `search` в списке нет — полнотекстовый поиск мерил через CLI.
3. `founder-board.json` не попал в базу: `gbrain import` берёт только markdown. Главный источник по деньгам и цели месяца в памяти отсутствует.
4. `gbrain think`/`synthesize` без ключа модели недоступны — зафиксировано, ключей не заводил.
5. Попутно: `hermes mcp remove` зависает без `y` на stdin.
