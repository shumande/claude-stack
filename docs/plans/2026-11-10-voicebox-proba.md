# Voicebox — проба клона голоса (10.11.2026)

**Вердикт: так себе.** Клон голоса на RU и DE получается и разборчив, но
сервер медленный и падает. Как рабочий инструмент не берём, пока не решено
на слух, похож ли голос.

## Что это

[voicebox.sh](https://voicebox.sh/) — бесплатная программа (MIT), всё локально:
клон голоса и озвучка, диктовка по горячей клавише, REST API `127.0.0.1:17493`
и MCP. Проверена версия 0.5.0 (релиз 25.04.2026), Mac Apple Silicon,
подпись Developer ID проверена (`spctl`: Notarized).

## Что проверено

Клон по 25 секундам живой записи автора, одна фраза на RU и DE, два движка.
Разборчивость — обратным распознаванием через Spokenly.

| Движок | RU | DE | Клон | Итог |
|---|---|---|---|---|
| Chatterbox Multilingual | 2 мелкие ошибки | слово в слово | да | рабочий |
| Qwen3-TTS 1.7B Base | чисто | 2 мелкие ошибки | да | рабочий, первая загрузка падает |
| Qwen CustomVoice 1.7B | — | — | нет (9 пресетов zh/en/ja/ko) | не подходит |
| TADA 3B ml | нет языка | есть | да | не подходит; нужна закрытая Meta Llama 3.2 (лицензия + ключ HF) |
| Kokoro | нет | нет | нет | уже используем отдельно (catsons) |

## Против (замеры)

- Скорость: около 10 минут на 13 с звука при пустой очереди;
  `/health` показывает `backend_variant: cpu`.
- Стабильность: Qwen падает при первой загрузке (`There is no Stream(gpu, 1)
  in current thread`); сервер упал SIGABRT дважды за 11 с (14:58).
- Один сервер на всех: параллельная сессия гоняла тот же Voicebox, задачи
  стоят в одной очереди.
- Диктовку не менять: Spokenly быстрее (замер 15.08: 0,6–2,5 с против 25 с у Whisper).
- Канон kors T-039: там только живая начитка, клон запрещён. Применимо лишь
  к линиям с аватаром.
