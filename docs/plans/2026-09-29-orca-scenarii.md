## Сценарии

| # | сценарий | чем лучше того, что есть | когда НЕ Orca |
|---|---|---|---|
| S1 | **Конкурс реализаций.** Одна задача с тестом → 2–3 worktree (Codex xhigh, Gemini, при нужде Claude). Каждый делает и прогоняет тест → сравнение по тестам и диффу → вливается один победитель, остальные worktree снимаются | `agent-council` даёт **мнения** (verdict-JSON), Orca — **работающие ветки**. Чипы Desktop гоняют только Claude | задача без проверяемого критерия (теста, числа) — там хватит совета |
| S2 | **Разгрузка лимита.** Длинная механика или тяжёлое чтение уходит Codex-воркеру в Orca. Claude пишет бриф с DoD и принимает дифф | тяжёлую часть оплачивает подписка ChatGPT. Заметка: `codex exec` в Bash делает то же без Orca — Orca добавляет живое окно, изоляцию и почту `worker_done` | задача на 1–2 файла — дешевле сделать в окне |
| S3 | **Эксперимент в защищённом репо.** Deploy-репо (push = деплой) и клиентские репо: эксперимент только в worktree Orca; наружу ничего, в main — только после гейта `codex-review` + `agy` | изоляция плюс видно, что делает каждый агент | всё, что уходит наружу, — никогда без «да» |

Правило выбора: одна модель → чип Desktop; нужны только мнения → `agent-council`; нужны несколько **реализаций** или Claude должен экономить лимит → Orca.
