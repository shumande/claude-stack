# Экономия токенов: Graphify и Code Mode для MCP

Заведено 11.11.2026 из главного окна. Чек-лист обновлять НА МЕСТЕ, не переписывать прозой.

## Почему
Лимит выгорает от кэша: контекст × число вызовов × модель (Правило 4, `~/.claude/CLAUDE.md`).
Замер 11.09.2026: блок имён коннекторов claude.ai = 11–19k токенов на окно в 85–93 % окон.
Две идеи от Алексея, обе — заявления авторов, не наш замер:
- Graphify (github.com/Graphify-Labs/graphify, Apache-2.0, PyPI `graphifyy`): граф кода вместо поиска по файлам, «минус 80 %».
- Cloudflare Code Mode / Anthropic «code execution with MCP»: агент пишет код к API инструментов вместо вызовов MCP по одному, промежуточные данные не идут через контекст.

## Против (заранее)
- В Claude Code схемы MCP уже грузятся лениво (ToolSearch) — часть выигрыша Code Mode уже взята.
- Graphify: разбор не-кода идёт моделью (платно); ещё один скилл в общем списке = прибавка к каждому вызову.
