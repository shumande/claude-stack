# Мульти-ИИ конвейер с мини-советом — дизайн (v1)

**Дата:** 2026-07-11
**Статус:** на сверку глазами (до кода)
**Первый узел:** грейд сценария kors

## Цель (одна строка)
Разные ИИ грейдят сценарий как **конвейер + мини-совет**, обмениваясь **тугим JSON**, без Алексея в петле. Доказать на живой задаче: (а) крутится сам, (б) экономит токены на проводе, (в) адаптеры переиспользуемы.

## Топология
Хребет — оркестрированный конвейер (DAG, инструмент Workflow). Автономии/шины/хаба НЕТ.
Одна стадия = **мини-совет**: N мозгов параллельно, каждый отдаёт компактный вердикт; синтезатор сводит. Наружу к Алексею — только финал.

```
[вход: сценарий]  →  [СОВЕТ: Claude ‖ Gemini ‖ Kimi ‖ GPT]  →  [синтез: 1 модель]  →  [финал Алексею]
        artefact            каждый → compact verdict JSON             merge + графты
```

## Компактный протокол (контракт между агентами)
Ключи — ТОЛЬКО ASCII `^[a-zA-Z0-9_.-]{1,64}$` (грабля StructuredOutput). Значения — любой язык.
Никакой прозы-для-человека в межагентном сообщении — проза только в финале синтеза.

```json
{
  "from": "kimi|gemini|gpt|claude",
  "verdict": "pass|weak|fail",
  "severity": 0,
  "cuts": [{"at": "хук|середина|финал", "why": "<кратко>"}],
  "root": "<корневая причина одной фразой>",
  "graft": ["<конкретная замена/строка>"]
}
```
Синтезатор ест массив таких объектов → отдаёт финальный грейд + отобранные графты (проза, только тут).

## Тонкие адаптеры (обёртка каждого мозга в ОДИН протокол)
Переиспользуют уже выверенные шимы — не изобретаем (см. `reference_kors_triada_models`).

| Мозг | Как зовём | $ сверху | Грабли, которые адаптер зашивает |
|---|---|---|---|
| Claude | нативно | $0 (подписка) | — |
| GPT | `codex-grade` шим | $0 (ChatGPT-подписка) | `read-only`+`ephemeral`, модель `gpt-5.5` |
| Gemini | `agy` шим, Pro High | $0 (Google-подписка, нед. квота) | виснет на промпте >13k → фолбэк OpenRouter |
| Kimi | moonshot curl | центы/ток | `temperature:1`, `max_tokens≥16k`, detached, `--max-time 900` |
| GLM | OpenRouter | центы/ток | **в первом совете пятым голосом** (решение Алексея 11.07); версию сверить перед привязкой ID (GLM-4.6 актуальна, «5.2» не подтверждён) |

Маржинальная цена прогона ≈ Kimi + (позже GLM) токены = центы. Три мозга из пяти на подписках.

## Что ЯВНО вне рамок
Нет websocket-хаба, нет пиринговой шины, нет автономного дискавери, нет нового сервиса.

## Доставка: как окно kors подхватывает архитектуру
Хребет живёт как **глобальный скилл** `~/.claude/skills/agent-council/` (совет+синтез+адаптеры) — все окна видят скиллы на «Старте сессии», значит любое БУДУЩЕЕ окно kors получает его автоматически. Оркестратор (это окно) СТРОИТ скилл; окно kors (исполнитель) его ЗОВЁТ и гоняет грейд — по правилу окон.

**Честная засада:** уже открытое окно kors загрузило скиллы на старте своей сессии — новый скилл оно само по себе не увидит. Два способа подхватить СЕЙЧАС:
1. перезапустить/переоткрыть то окно (перечитает скиллы + CLAUDE.md) — durable путь; или
2. без перезапуска: в том окне ткнуть в скрипт напрямую — `Workflow({scriptPath: "<путь>"})` гоняет файл живьём, перезагрузка не нужна.

## Критерии успеха (проверяемые)
1. Конвейер отрабатывает грейд end-to-end **без Алексея в середине**.
2. Финал ≥ по качеству текущей ручной триады (сверка на 1 боевой партии).
3. **Замер:** токены на проводе (JSON) < базлайна на прозе — цифрой, не на веру.
4. Адаптеры вынимаются как модуль и цепляются к следующему воркфлоу без правок.

## Решения (11.07)
- Синтезатор = **Claude** (дефолт, хребет-голос триады).
- Первый совет = **5 голосов**: Claude / Gemini / Kimi / GPT / GLM.
